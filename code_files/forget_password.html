খামারীকা

কৃষির প্রতিটি ধাপে,
আপনার বিশ্বস্ত সাথী।

একটি অ্যাকাউন্টেই আপনার খামার, ফসল, বিশেষজ্ঞের সহায়তা ও নিজের বাজার।

✓ সহজ ব্যবস্থাপনা
✓ সঠিক সময়ে বিশেষজ্ঞের যোগাযোগ
✓ সরাসরি কৃষক–ক্রেতার সংযোগ

পাসওয়ার্ড ভুলে গেছেন?

চিন্তা করবেন না। আপনার নিবন্ধিত মোবাইল নম্বর বা ইমেইল লিখুন, আমরা পাসওয়ার্ড রিসেট করার পদ্ধতি পাঠিয়ে দেব।
